# Technical Decisions

I selected the overall application architecture and technology stack for the project.

## Backend

- Python 3.13
- Django 5.2
- Django REST Framework 3.16
- PostgreSQL 16

## Frontend

- Angular 21.2
- Angular Material/CDK 21.2
- TypeScript
- d3 (`d3-scale`, `d3-array`, `d3-shape`, `d3-format`) for calculations and data visualization, with SVG rendered through Angular templates

## UI / Design

The interface was designed around a modern responsive layout with interactive components, smooth transitions, and scroll-based presentation elements. The goal was to create a polished application experience rather than rely on automatically generated UI patterns.

## Fonts

- Archivo Variable
- IBM Plex Mono

## Infrastructure

- Railway for frontend, backend, and PostgreSQL hosting
- Gunicorn as the production WSGI server
- Whitenoise for serving static files
